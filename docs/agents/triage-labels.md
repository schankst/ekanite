# Triage Labels

Die Skills sprechen von fünf kanonischen Triage-Rollen. Diese Datei mappt Rollen auf die konkreten Label-Strings in diesem Tracker.

| Rolle in mattpocock/skills | Label im Tracker | Bedeutung |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer muss dieses Issue bewerten |
| `needs-info`               | `needs-info`         | Wartet auf mehr Infos vom Reporter |
| `ready-for-agent`          | `ready-for-agent`    | Vollständig spezifiziert, bereit für einen Agenten |
| `ready-for-human`          | `ready-for-human`    | Erfordert menschliche Implementierung |
| `wontfix`                  | `wontfix`            | Wird nicht umgesetzt |

Wenn ein Skill eine Rolle erwähnt (z. B. "apply the AFK-ready triage label"), den entsprechenden Label-String aus dieser Tabelle verwenden.

Hinweis: `wontfix` existierte bereits und bleibt; die anderen vier wurden beim Setup angelegt.
